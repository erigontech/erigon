### Skills to Know About
- `/simplify` — Simplify or refactor a piece of code. Useful when a function or block feels overcomplicated.
- `/compact` — Compact the conversation context when it's getting long. Use before hitting context limits.
- `/model` — Switch Claude model mid-session. Useful to step up to Opus for harder reasoning tasks.
- `/data-colocation-advisor` — Custom skill for analyzing data colocation and page-cache locality in snapshot files.
- `/security-review` — Review the current diff for security issues.
- `/effort` — Adjust how much effort Claude spends on a task (low/medium/high).
- `/plan` — Enter plan mode to design an implementation approach before writing code.
